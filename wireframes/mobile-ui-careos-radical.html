Radical concept

VitalScan CareOS, not another lab test catalogue

This direction intentionally breaks away from Healthians colors and catalogue structure. It uses an ink, coral, cyan, lime, and yellow system; a health lens home; assistant-led booking; a coverage matrix; a visit choreography screen; and a magazine-style report story.

VIS
Different visual systemNo teal-led healthcare template. Black command surfaces, coral action, cyan data, lime recovery, yellow caution.
UX
Different navigation modelThe app starts from a personal health lens and next action, not banners and package cards.
AI
Different booking modelUsers describe intent, then VitalScan builds a useful package and explains coverage.
