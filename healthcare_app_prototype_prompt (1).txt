  - Banner carousel: CSS translateX auto-scroll every 4s
  - Health score ring: SVG stroke-dashoffset animate on screen enter, 1.2s ease-out
  - Quick action grid: stagger fade-in, each icon 60ms delay apart
  - Package cards: slide-in from right on first render

BOOKING FLOW
  - Step progress bar: animate width fill on each step advance
  - Confirmation: checkmark draws itself (SVG stroke animation), then bounces
  - Slot pills: pop-in scale animation when slots load

AI COPILOT
  - Typing indicator: three dots bounce sequentially (CSS keyframes)
  - Message bubbles: slide-up + fade-in as each message appears
  - Pre-prompt chips: stagger reveal on screen enter

REPORT DETAIL
  - Parameter rows: stagger slide-in from left, 40ms apart
  - Abnormal values: pulse red glow animation (subtle)
  - Trend sparkline: draw left-to-right on enter

HEALTH SCORE
  - Circular gauge: animate stroke from 0 to score, 1.5s ease-out
  - Sub-score bars: animate width fill with 100ms stagger
  - Score number: count-up animation from 0 to actual score

GENERAL (apply to all screens)
  - Screen enter: opacity 0 to 1 + translateY(10px) to 0, 250ms
  - Screen exit: opacity 1 to 0, 150ms
  - Cards on scroll: intersection observer fade-up reveal
  - All buttons: transform scale(0.97) on active press
  - Bottom nav icon: scale bounce on tap
